# AWS Monitoring & Auditing Lab

## Overview
Explored AWS monitoring and auditing services to gain visibility into infrastructure performance and account activity.

## Configurations & Activities
- **Amazon CloudWatch:** Monitored EC2 CPU and network metrics.
- **EC2 Status Checks:** Reviewed system, instance, and EBS status checks.
- **AWS CloudTrail:** Explored event history to understand AWS account activity and API events.

## Key Skills
Cloud monitoring · Metric analysis · Infrastructure health checks · Activity logging · AWS auditing
