# AWS EBS Storage Lab

## Overview
Configured Amazon Elastic Block Store (EBS) to provide persistent block storage for an EC2 instance.

## Configurations
- Created and configured an EBS volume.

![Created EBS Volume](screenshots/Created%20EBS%20Volume.png)
- Attached the volume to an EC2 instance.
- Formatted and mounted the volume in Ubuntu.
- Created test files to verify storage functionality.
- Explored EBS snapshots for data backup.

## Key Skills
EBS volume management · Volume attachment · Linux disk formatting and mounting · Data persistence · Snapshots
